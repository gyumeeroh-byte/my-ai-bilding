# MY AI BILDING

AI 도구를 넘어, 나만의 창작의 성을 짓다.

글·그림·영상·목소리·음악 도구를 세 층의 빌딩으로 정리하는 한국어 웹입니다.

- 1층: 회사·기본 AI
- 2층: 특화 제작 서비스
- 3층: 실행·편집·연결 작업공간

## 사용하기

‘내 빌딩 만들기’에서 환경을 확인하고, 요청문을 사용하는 AI에 붙여넣으세요. AI가 만든 JSON 목록을 가져와 검토하거나 도구를 직접 등록할 수 있습니다.

‘예시 빌딩 보기’에서는 실제 서비스 19개의 활용 예시와 작업 연결 순서를 살펴볼 수 있습니다. 예시는 개인 목록에 저장되지 않습니다.

## 개인 목록과 백업

개인 목록과 관리 메모는 현재 브라우저의 저장 공간에 저장됩니다. 이 사이트는 개인 목록을 서버나 GitHub 저장소에 전송하지 않습니다. 다른 기기로 자동 동기화하지 않으며 브라우저 데이터 삭제 시 사라질 수 있습니다.

‘백업·기기 옮기기’에서 JSON 파일을 내려받아 보관하고 다른 기기에서 가져오세요. 로컬 파일로 쓰던 목록은 공개 웹으로 자동 이동하지 않습니다. 기존 화면에서 백업한 뒤 공개 웹에서 가져오세요.

비밀번호·API 키·토큰은 입력하지 마세요. 관리 메모는 별도 보안 기록의 보관 위치만 적는 곳입니다. 브라우저 저장과 JSON 백업은 암호화된 금고가 아닙니다.

## 기능의 범위

이 웹은 PC·계정 자동 검사, AI API 호출, 에이전트 자동 실행을 하지 않습니다. 조사와 답변은 사용자가 선택한 AI에서 진행합니다. 설치·로그인 상태와 출처는 직접 검토하세요.

## GitHub Pages

저장소의 Settings → Pages에서 Source를 `Deploy from a branch`, Branch를 `main`, 폴더를 `/(root)`로 설정합니다.

`index.html`, `my-ai-building-intro.mp4`, `my-ai-building-intro-poster.jpg`는 같은 폴더에 둡니다. 빌드나 별도 패키지 설치가 필요하지 않습니다.

이 저장소에는 공개 웹과 소개 영상·포스터만 포함합니다. 개인 목록, 키 관리 노트, PC 조사 파일, 브라우저 백업은 올리지 마세요.
