AI 도구를 넘어,
나만의 창작의 성을 짓다.

설치한 프로그램부터 웹에서 쓰는 서비스까지. AI와 함께 도구를 정리하고, 나에게 맞는 활용법을 찾아보세요.

이 사이트는 PC나 계정을 자동 검사하지 않습니다. 사용하는 AI에게 요청문을 복사해 조사하고, 결과를 검토한 뒤 등록합니다.

개인 목록은 이 브라우저에만 저장됩니다. 다른 기기로 옮기려면 백업 파일을 사용하세요.
시작 전에 알고 싶어요

PC 직접 조사는 로컬 파일·명령·브라우저 접근을 지원하는 AI와 허용된 권한이 필요합니다. 일반 AI 채팅에서는 목록이나 필요한 화면을 직접 제공하면 됩니다.

무료·유료보다 실제 사용 가능한 기능을 확인하세요. 웹 검색·첨부·질문 한도는 서비스마다 다릅니다. 이 사이트 자체는 AI API를 호출하지 않습니다.

키·비밀번호·토큰은 입력하지 마세요. 개인 관리 메모는 보관 위치를 적는 용도이며 암호화된 금고가 아닙니다.

AI와 함께 내 도구 정리하기

어떤 방식으로 조사할까요?

웹 로그인은 해당 서비스에서 직접 진행하세요. 비밀번호·인증코드는 AI에게 전달하지 않습니다.

어느 AI에 붙여넣으면 좋을까요?

기능·회사·이용 조건 조사는 웹 검색이 가능한 대화가 적합합니다. 내 설치 프로그램·버전 확인은 내 PC에 연결된 Codex 등 로컬 작업형 AI가 적합할 수 있습니다.

클라우드 작업 환경과 내 PC는 다를 수 있고, 파일 접근만으로 웹 로그인까지 확인되지는 않습니다. 필요한 접근 범위를 먼저 확인하고, 보안 제한을 임의 해제하지 마세요.

요청문을 복사해 AI에 보내세요

복사 → 사용하는 AI 대화창에 붙여넣기 → 전송. AI가 결과를 주면 다음 단계로 이동합니다.

입력 내용과 요청문은 외부로 자동 전송되지 않습니다. 조사 요청은 읽기 전용이며 설치·삭제·업데이트·결제를 요청하지 않습니다.

AI 결과 또는 백업 파일 가져오기

AI 답변 중 등록 목록 부분을 복사하거나, 백업 JSON 파일을 선택하세요. 파일 내용은 이 브라우저에서만 읽습니다.

어떤 부분을 복사해야 하나요?

AI 답변의 ‘[’로 시작해 ‘]’로 끝나는 JSON 목록을 복사하세요. JSON 코드블록 전체를 복사해도 됩니다. 설명 문장이나 질문 자체를 넣으면 등록할 수 없습니다.

등록 전 확인

도구처리분야·층확인 상태근거

기존 도구를 지우지 않고 추가·업데이트합니다. 잘못 반영했다면 ‘되돌리기’를 사용할 수 있습니다.

나의 AI 빌딩

이야기를 쓰고, 그림과 소리를 더해 영상으로 완성하는 창작자

회사·기본 AI를 고르는 1층, 결과물을 만드는 2층, 편집하고 연결하는 3층을 함께 둘러보세요.

읽기 전용 예시입니다. 내 목록에 저장되지 않으며 설치·로그인 상태를 뜻하지 않습니다.

첫 도구부터 채워볼까요?

아직 내 도구가 없습니다. AI와 함께 목록을 모으거나, 알고 있는 도구를 하나씩 추가하세요.

작은 화면에서는 목록 보기가 더 편리합니다. 건물은 좌우로 밀어 볼 수 있어요.

조건에 맞는 도구가 없습니다.

이 도구들을 이렇게 연결해요

만들고 싶은 결과를 골라 작업 순서를 살펴보세요. 도구 이름을 누르면 설명이 열립니다.

에이전트 관제탑

기획 → 사실·출처 확인 → 제작 → 검수의 역할을 나눕니다.

기획은 대화 AI, 제작은 분야별 서비스에 맡기고 최종 판단은 사람이 합니다. 이 예시에서 에이전트가 자동 실행되지는 않습니다.

공통 자산 관리실

프롬프트·원본·출처·이용 조건·최종본의 위치를 모아 둡니다.

예: Obsidian에는 작업 기록, GitHub에는 웹·코드의 변경 이력. 인증정보는 별도 보안 기록으로 관리합니다.

만들고 싶은 것부터

분야를 고르면 기본 작업 흐름을 볼 수 있습니다. 내 도구의 실제 사용 조건은 따로 확인하세요.

세 층의 기준이 궁금해요

1층 회사·기본 AI: Claude—Anthropic, Gemini—Google처럼 기본 AI와 제공 회사.
2층 특화 제작 도구: Suno·Flow처럼 특정 결과물 제작.
3층 통합·편집·연결: Higgsfield·GitHub·편집기처럼 기능과 자료를 모아 활용.

성능·가격 순위나 엄밀한 기술 모델 계층이 아닌 사용자 관리 기준입니다. 주 역할 한 층과 여러 분야로 표시합니다. 같은 도구가 여러 분야에 나타나도 저장 항목은 하나입니다.

작업 역할·공통 자산 안내

기획·사실확인·글쓰기·영상·소리·썸네일·소재 관리 역할을 생각하며 작업을 나눠보세요. 이 화면에서 별도의 에이전트가 자동 실행되지는 않습니다.

원본 파일·출처·권리·프롬프트·검수 결과는 사용하는 기록 앱이나 폴더에 보관하세요. 이 사이트의 개인 관리 메모에는 인증정보 원문 대신 보관 위치만 적습니다.

새 도구 등록

직접 확인하지 않은 설치·로그인 상태는 ‘미확인’으로 남겨주세요.

분야 · 여러 개 선택 가능
이 양식은 키·비밀번호를 보관하지 않습니다. 공개 HTTPS 홈페이지 주소를 사용하고 인증용 링크·쿼리·계정정보는 넣지 마세요.

새 AI 도구 등록하기

기능을 알고 있다면 직접 등록하고, 잘 모른다면 AI에게 질문해 보세요.

AI에게 이렇게 물어보세요

  1. 사용하는 AI에 이 사이트의 공개 주소 또는 아래 ‘등록 양식 안내 파일’을 전달하세요.
  2. 도구 이름·주소를 입력하고 요청문을 복사해 전송하세요.
  3. AI가 만든 등록 목록을 가져와 확인한 뒤 저장하세요.
현재 로컬 HTML의 file:/// 주소는 다른 AI가 열 수 없습니다. 안내 파일을 첨부하거나 아래 상세 질문을 사용하세요. 웹 검색·첨부 지원과 한도는 서비스마다 다릅니다.
사이트나 파일을 AI가 읽지 못한다면

등록 기준과 결과 양식이 포함된 상세 질문을 복사하세요. 이 질문만으로도 형식을 전달할 수 있습니다.

다른 방법을 알아보고 싶어요

원하는 결과와 조건을 적으면 AI에게 물어볼 질문을 정리합니다. 답변은 사용하는 AI에서 받습니다.

예시인지 내 목록인지 확인하고 선택하세요. 개인 관리 메모·기기명·파일 경로는 포함하지 않습니다.

백업·다른 기기로 옮기기

이 사이트는 자동 동기화를 하지 않습니다. 백업 파일을 다른 브라우저에서 가져오면 목록과 선택한 메모를 이어갈 수 있습니다.

포함: 도구 목록, 확인 상태, 근거, 날짜와 선택한 개인 관리 메모.
미포함: 영상·포스터·HTML 파일과 로그인 정보.

JSON 백업은 암호화되지 않습니다. 인증정보는 넣지 말고 보관 위치 메모도 공유 전에 확인하세요.

로컬 파일로 사용할 때 주의할 점

브라우저 데이터 삭제나 파일 위치 변경 시 목록을 읽지 못할 수 있습니다. 변경 후 백업을 권합니다. HTML·소개 영상·포스터는 같은 폴더에 두세요. 외부에 공개하려면 호스팅 작업이 별도로 필요합니다.

내 선택으로 도구를 모으고, 확인된 근거로 활용하기. AI 조사와 분류 제안은 직접 검토하세요.
